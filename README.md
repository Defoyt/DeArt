# DeArt — Веб-галерея цифрового искусства и картин

**DeArt** — это веб-приложение на Django для публикации, просмотра и обсуждения художественных работ и фотографий. Проект разработан в рамках финального задания.

---

##  Функционал проекта

###  Работа с публикациями (CRUD):
* **Просмотр ленты:** Главная страница с сеткой опубликованных работ.
* **Детальная страница:** Просмотр картины в высоком разрешении, её описания, автора и даты публикации.
* **Добавление работ:** Загрузка новых изображений с указанием названия, описания и категории.
* **Редактирование и удаление:** Авторы могут редактировать или удалять только **свои** публикации (защита на уровне `views` и шаблонов).

###  Поиск и фильтрация:
* Поиск картин по названию и описанию.
* Фильтрация публикаций по выбранной категории.

###  Интерактивность и статистика:
* **Система лайков:** Возможность ставить и снимать лайки с динамическим счётчиком.
* **Избранное:** Сохранение понравившихся картин в личную коллекцию.
* **Счётчик просмотров:** Автоматический учёт просмотров при каждом открытии страницы работы.
* **Комментарии:** Авторизованные пользователи могут оставлять комментарии под публикациями.

###  Профиль и авторизация:
* Регистрация новых пользователей, вход и выход из системы.
* Страница профиля автора со списком всех его публикаций и **автоматическим подсчётом количества опубликованных работ**.

---

##  Технологический стек

* **Backend:** Python 3.12+, Django 5.0+
* **Database:** SQLite3
* **Frontend:** HTML5, CSS3 (Кастомная тёмная тема `#0b132b` / `#1c2541`)
